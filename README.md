# DX12Board

DirectX 12를 이용하여 제작한 3D 칠판 프로그램입니다.

## 주요 기능

- 3D 칠판에 마우스로 자유롭게 그림 그리기
- 6가지 분필 색상 선택 및 부분 지우개 기능
- 분필과 지우개 굵기 조절
- BMP 이미지 저장 및 불러오기
- 저장한 그림을 불러온 후 이어 그리기
- 칠판 전체 지우기
- 카메라 회전 및 초기화

## 조작 방법

| 조작 | 기능 |
|---|---|
| 마우스 좌클릭 드래그 | 그림 그리기 / 지우기 |
| 마우스 우클릭 드래그 | 카메라 회전 |
| R | 카메라 초기화 |
| 1~6 | 분필 색상 선택 |
| E | 지우개 선택 |
| Save BMP | 그림 저장 |
| Load BMP | 저장한 그림 불러오기 |
| Clear Board | 전체 지우기 |
| Brush - / + | 분필 및 지우개 굵기 조절 |

분필 색상과 지우개는 칠판 아래 팔레트를 마우스로 클릭하여 선택할 수도 있습니다.

## 실행 방법

1. Visual Studio 2022에서 `DX12Board.sln` 파일을 엽니다.
2. `Debug / x64` 환경에서 빌드 후 실행합니다.

※ 셰이더 파일을 찾지 못하는 오류가 발생하면 프로젝트 속성 → 디버깅 → 작업 디렉터리를 `$(ProjectDir)`로 설정해 주세요.
